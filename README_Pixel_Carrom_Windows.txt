PIXEL CARROM — WINDOWS

1. Extract Pixel_Carrom_Windows.zip.
2. Double-click pixel_carrom_windows.html.
3. Open with Microsoft Edge or Google Chrome if prompted.

CONTROLS
- Move mouse to aim.
- Click and drag backward from the striker, then release to shoot.
- Or use A/D (or Left/Right arrows) to aim.
- W/S (or Up/Down arrows) adjust power.
- Space or Enter shoots.
- New Game resets the board.

Runs locally in your browser; no installation or internet connection required.
This is a casual local two-player game, not a standalone .EXE yet.
